Colors

Never hardcode a hex value in a template or a new CSS rule — every color below is a variable in :root (and re-declared under [data-theme="dark"] where the value needs to flip).

--text-accent is --primary in light mode but swaps to the lighter --primary-light in dark mode, because full-saturation red reads harshly on a near-black page. Use it (not --primary directly) for any text that sits straight on --bg/ --surface — headings, links, stat numbers. --primary itself is still correct for anything with its own background, like a button or badge.

--page-bg / --card-bg are the other theme-flip pair: a .card needs to read as "elevated" above the page in both themes, which means white-on-light-gray in light mode but light-gray-on-near-black in dark mode — opposite directions. Use .card/.stat-tile rather than wiring these two up yourself.

Buttons

Hover any of these — they lift 1px and darken/raise slightly. If you add a new .btn-* variant, its :hover rule must re-declare its own color: the global a:hover rule otherwise outranks a plain .btn-* color on specificity and can make the label invisible against its own hover background (this bit the hero/CTA buttons once — see the comment above .btn-primary in theme.css).
